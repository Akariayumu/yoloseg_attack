# 实现与实验路线

## 总原则

每次只引入一个变量，完整推理复核后再进入下一闸门。第三方仓库仅作为参考；无明确许可证的源码不复制进主工程。

## M0：协议冻结与回归测试

状态：待执行

- 固定人物冻结集、位置搜索集与最终测试集，三者实例不重叠。
- 将当前 `0.2%` 面积、检测保持阈值和 EOT 范围写入 YAML。
- 增加区域外像素完全不变、alpha 范围、随机种子复现测试。
- 保存无防御与现有 JPEG/Gaussian 结果作为诊断基线。

闸门：现有局部纹理攻击结果可从配置重复，完整推理指标一致。

## M1：位置搜索 + 2D EOT

状态：下一步

- 实现服装可行域内候选网格和 mask-head 梯度敏感度。
- 加入检测保持风险和越界惩罚；显著性先用轻量梯度/颜色对比代理。
- 实现 batch EOT 采样器及变换参数日志。
- 比较固定位置、随机位置、仅敏感度、完整评分四组。

闸门：至少在冻结 pilot 上比固定位置提高 SDR，且 box IoU/置信度不恶化；在独立 EOT 种子上仍成立。

## M2：日常服装纹理先验

状态：未开始

- 先加入 TV、有限服装调色板和可重复平铺。
- 再加入 VGG 内容/风格损失；VGG 只作 frozen feature extractor。
- 最后消融 Voronoi + Gumbel-softmax，不引入 3D 渲染。
- 同时报告攻击效果和自然性代理，避免只挑“最好看”的样本。

闸门：在相同面积/alpha/步数下，自然性指标改善且 SDR 不出现不可接受下降。

## M3：两阶段透明度

状态：未开始

- 阶段 A 固定 alpha 优化纹理；阶段 B 冻结纹理优化 alpha logits。
- 比较固定 alpha、联合优化、两阶段优化。
- 对 alpha 均值和有效面积做严格等预算；绘制效果—可见性 Pareto 曲线。

闸门：两阶段方案在相同攻击成功率下减少 alpha/感知距离，或在相同 alpha 下提升成功率。

## M4：自适应防御评测

状态：未开始

- 输入净化：JPEG、blur、位深、随机 resize/pad。
- 定位/修复：先用轻量局部异常基线，再隔离运行 NAPGuard。
- 所有不可微步骤加入 BPDA/STE；真实前向复核。
- 比较定位 mIoU 与最终 mask 恢复，检查二者是否脱钩。

闸门：只有自适应结果可进入主表；非自适应结果标为 diagnostic。

## M5：训练型防御

状态：未开始

- 建立已知纹理/未见纹理、已知位置/未见位置划分。
- 实现 PBCAT 式局部梯度贴片 + 全局小扰动的复合训练 batch。
- 先微调 head，再评估全模型训练；持续监控 clean COCO AP。
- 与普通 patch adversarial training、只净化、只定位比较。

闸门：未见纹理和 OOD EOT 上有稳定提升，且 clean bbox/mask AP 下降在预设容忍范围内。

## M6：物理与多视角验证

状态：条件式

- 数字结论稳定后再增加 TPS、打印色域和相机响应。
- 同一纹理跨视频帧/视角共享，加入时序一致性防御。
- 先做打印-拍摄小样，再决定是否搭建 Mitsuba/PyTorch3D 3D 环境。

闸门：数字 EOT 与实拍方向一致；若不一致，优先修正变换分布而不是扩大扰动预算。

## 推荐近期任务顺序

1. M0 配置和回归测试。
2. M1 候选位置评分。
3. M1 EOT 与独立种子评测。
4. 首轮自适应 JPEG/Gaussian 复核。
5. 达到闸门后才进入 M2。
