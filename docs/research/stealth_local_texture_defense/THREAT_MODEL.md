# 防御评测威胁模型

## 研究目的

验证 YOLO-Seg 防御在隐蔽、局部、可变换纹理下是否仍能保持人物检测和实例分割质量。攻击器是评测工具；所有结论限定在公开模型、公开数据和授权实验环境中。

## 攻击者能力

- 白盒访问受害 YOLO-Seg 的梯度；另设迁移黑盒测试。
- 只能修改目标人物实例内预先定义的服装可行域。
- 单个连通区域，默认面积不超过整图 `0.2%`，同时报告相对人物框面积。
- 可优化 RGB 纹理和透明度；不能修改区域外像素。
- 可在已声明的变换分布上优化期望损失。
- 自适应实验中知道防御算法和公开参数，但不知道独立测试种子。

## 攻击目标

主目标为降低指定实例的 mask IoU 或 Boundary IoU，同时保持：

- 类别仍为 person；
- confidence 不低于协议阈值；
- box IoU 不低于 `0.90`；
- 非目标实例和全图误检变化受限。

最终判定只使用完整 Ultralytics 推理、NMS 和 mask 后处理。训练期 raw-head 代理不得替代最终结果。

## 四组件参数化

### 位置搜索

只在服装可行域内枚举候选窗口。评分由下列标准化项组成：

```text
score = mask_sensitivity
        - lambda_det * detection_risk
        - lambda_sal * perceptual_saliency
        - lambda_oob * clothing_boundary_violation
```

位置选择必须与纹理优化数据分离，防止在同一批样本上挑选后再报告。

### 服装纹理先验

逐层消融：

1. TV + 有限调色板；
2. VGG 内容/风格约束；
3. Voronoi 单元 + Gumbel-softmax 离散颜色；
4. 可重复平铺约束。

每层保持相同面积、alpha 和优化步数预算。

### 两阶段透明度

- 阶段 A：固定 `alpha = alpha_max`，优化 RGB。
- 阶段 B：冻结 RGB，优化 alpha logits。
- 阶段 B 加入平均 alpha、二值/平滑和最小有效面积约束。
- 必须与联合优化和固定 alpha 做同预算消融。

### EOT

首版分布：平移、尺度、旋转、透视、亮度、对比度、轻噪声、Gaussian blur。第二版加入 TPS、遮挡、打印色域和相机颜色响应。

每个样本记录变换参数；训练和测试使用不同种子，另设超出训练范围的 OOD 变换。JPEG/量化/硬 mask 防御使用 BPDA 或 STE 求梯度，但成功与否在真实算子前向上判断。

## 防御知识条件

| 条件 | 攻击是否知道防御 | 用途 |
|---|---|---|
| 无防御 | 不适用 | 攻击强度上限 |
| 非自适应 | 否 | 仅作诊断，不支持稳健性结论 |
| 自适应 | 是 | 主防御结论 |
| 迁移黑盒 | 只知道防御类别 | 测试跨模型/参数迁移 |
| OOD | 不知道保留纹理与变换 | 测试泛化 |

## 指标

攻击/任务：SDR、DPR、target mask IoU、Boundary IoU、box IoU、confidence、COCO bbox/mask AP、非目标 FP/FN。

防御：防御后 SDR/DPR、目标恢复率、贴片 NmIoU/SmIoU、干净 AP 下降、误报率、时延和显存。

自然性/预算：全图与框内面积比、平均/最大 alpha、LPIPS、SSIM、CIEDE2000、TV、调色板大小、服装区域越界率；物理阶段补充盲评和打印-拍摄结果。

## 成功与停止条件

只有同时满足检测保持和掩码退化才计为攻击成功。防御只有在自适应攻击下提升目标恢复、干净 AP 代价可接受且不依赖已知纹理时才视为有效。

若攻击只能通过放宽面积/alpha 预算成功，或防御优势在 BPDA/EOT 后消失，应记录为负结果，不继续调参掩盖。
