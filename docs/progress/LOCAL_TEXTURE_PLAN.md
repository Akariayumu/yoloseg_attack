# 局部纹理攻击与防御路线

## 参考方法

参考 `chen37058/Physical-Attacks-in-Embodied-Nav` commit `8991780` 及其 IROS 2025
论文。原方法在 3D 场景中优化附着于物体的纹理和透明度，并使用对象感知的多视角相机
采样；纹理与透明度分两阶段优化，以兼顾攻击效果和自然性。

## 与 YOLO-Seg 的映射

1. 数字局部纹理：在冻结人物框内放置固定面积矩形贴片，区域外像素严格不变。
2. 可学习透明度：`x_adv = (1-alpha*M)*x + alpha*M*texture`，先优化纹理再优化 alpha。
3. EOT：对缩放、透视、亮度、对比度、模糊和 JPEG 进行期望损失优化。
4. 多视角：同一目标的视频帧或合成视角共享一张纹理，报告跨视角 SDR/DPR。
5. 物理阶段：打印色域/NPS、总变分、面积和透明度约束，最后再做实拍验证。

## 防御矩阵

- 输入净化：JPEG、Gaussian/median blur、位深压缩；同时报告干净精度代价。
- 贴片定位：高频/显著性异常与实例内部局部一致性，检测后局部修复而非全图模糊。
- 随机化：随机缩放、padding、JPEG 和轻度颜色变换。
- 多视角一致性：相邻帧的框稳定但掩码异常突变时触发告警或时序融合。
- 自适应评测：攻击优化中包含防御变换；不可微防御使用 BPDA/EOT，避免虚假安全感。

## 首次单图可行性结果

贴片占整图 `0.001709`，100 步 dynamic-weight 的官方完整推理结果为 confidence
`0.623`、box IoU `0.927`、mask IoU `0.314`，命中选择性退化。非自适应防御中，JPEG
Q95 将 mask IoU 恢复到 `0.523`，Gaussian sigma=1.0 恢复到 `0.689`，两者均保持目标
检测。结论仅限单图探索，不能视为防御有效性结论。
