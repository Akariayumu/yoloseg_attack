# 项目进度与路线图

本目录是项目执行状态的唯一入口，用于区分“研究计划”“当前事实”和“历史记录”。

## 文件说明

| 文件 | 用途 | 更新时机 |
| --- | --- | --- |
| [`STATUS.md`](STATUS.md) | 当前进度、阻塞项、下一批任务 | 每次完成可验收任务后 |
| [`ROADMAP.md`](ROADMAP.md) | 阶段目标、依赖关系、通过判据 | 研究范围或阶段安排变化时 |
| [`LOG.md`](LOG.md) | 按日期记录重要实现、实验和决策 | 每个工作日或关键变更后 |

## 维护规则

1. 只有通过测试或产生可检查产物的任务才能标记为“完成”。
2. 实验结果必须同时记录配置、随机种子、模型哈希和输出目录。
3. 阶段门槛未通过时，不把后续实验结果作为正式结论。
4. `STATUS.md` 只保留当前状态；历史变化写入 `LOG.md`。
5. 改动评测阈值时必须提升协议版本，冻结的参照集不得覆盖。
